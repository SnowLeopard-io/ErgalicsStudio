# 11 · 插件科研化整改方案

> 适用范围：`src/plugins/builtin/` 下的内置科研插件（含 `geo/`、`env/`、`bio-*`、`chem-*`、`ai-training` 等）。
> 豁免范围：`em-eigensolver`（电磁谐振特征值求解器）与 `fluid-cfd-coupler`（流体双向耦合求解器）已具备研究级内核，不作为本方案整改对象，仅作为"研究级"参照基准。
> 依据：本方案所有结论均来自对插件源码的逐项审阅，结论处标注 `文件:位置` 证据。

---

## 1. 结论综述

对 56 个内置科研插件（排除两个 Python 求解器）按六项标准评级：**数据驱动性、算法严谨性、数值健壮性、科学输出、导出与可复现、单位与量纲**。评级分布：

| 级别 | 数量 | 共同特征 | 代表性插件 |
| --- | --- | --- | --- |
| 研究级 | 2（豁免） | 文献算法 + 参考解对拍 + 真实残差认证 + bench/test | EM 特征值、CFD 耦合器 |
| 准研究级 | ≈20 | 真实数据输入与正确内核，缺科学输出 / 诊断 / 对拍 / 复现 | bio-enzyme、spatialInterp、terrain、nbody、chem-crystal |
| 演示级 | ≈23 | 可加载数据，但输出仅为可视化，无数值结论 | fluid、wave、optics、structure、heatmap、networkGraph |
| 教学玩具级 | ≈13 | 参数滑块驱动、内置/近似数据或零维模型 | greenhouse、carbon、plume、globe、bio-popgen、sankey |

**三个根因：**

1. **插件定位偏"教学示意"**。部分 manifest 的 `descriptionI18n` 明示教学属性，如 `src/plugins/builtin/env/greenhouseManifest.ts:18`「教学示意，不能用于预测真实气候」、`site/env/earth3d.ts` 及 `groundwater3dManifest.ts:18`「示意性 / 不用于场地评估」。
2. **数值内核偏好可视化而非严谨计算**：多处使用固定步长、像素/观感缩放常数。如 `electromag.ts:43-46` 的 `K=4e6、MIN_R=18、MAX_V=2400`，`wave.ts:100` 的 `damping=0.999`，`structure.ts:43-55` 的材料强度经像素比例缩放。缺少收敛判据、守恒诊断与解析解对拍。
3. **科学输出断链**：多数插件"算完只画图"，不给统计量、拟合误差、不确定度，也未接入项目已有的可复现内核（`src/core/repro/`）与运行血缘（`runs` / `lineage`）。

## 3. 整改框架（五层）

### L1 基础设施整改 —— 改动最小、全体受益

- 在插件契约中扩展 `research` 元数据（`tier` / `units` / `benchmarks` / `reproducible`），界面按级渲染"研究级 / 准研究级 / 演示级 / 教学演示"徽章。
- 审计"空数据禁止出图"门禁：将源码注释承诺的"初始为空、绝不伪造默认场景"落实为行为约束。
- 统一科学输出栏组件：R²、残差、置信区间、收敛/守恒诊断的通用展示。
- 统一接入 `src/core/repro/`（种子随机数、稳定哈希）与 `runs` / `lineage`（运行记录与血缘）。

### L2 补齐科学输出 —— 约 20 个准研究级插件转正

内核正确、缺"讲出结果"：

- **bio-enzyme**：已有 R²/RMSE（`plugin.ts:8`），补参数置信区间、残差图、文献 Km 对比。
- **spatialInterp**：已有 LOOCV + Moran's I（`spatialInterp.ts:366-435`），补预测标准误面与 CV 汇总表。
- **terrain**：补流域统计、坡度/坡向误差带、投影与单位输出。
- **nbody / doublePendulum / chem-crystal / chem-reaction / aqi / water / biodiversity / plume3d / lake3d / geoMap / solar / climograph / geoMeasure / tissot**：按各自短板补诊断与导出。

### L3 数值内核升级 —— 演示级 → 准研究级

- **wave / fluid**：补收敛判据与解析解对拍，保留守恒量诊断。
- **electromag / optics / structure**：去除像素/观感缩放常数，建立真实单位制与守恒/能量诊断。
- **统计图表簇（约 20 个）**：从"绘图"升级为"分析"——每张图配套统计摘要、假设检验、置信区间、分箱/核带宽自动选择算法。

### L4 旗舰深挖 —— 对齐两个求解器的研究级标准

以 `em-eigensolver`（`validate_correctness.py`：LAPACK 对拍 + 真实残差认证；`benchmarks/perf_bench.py`；`tests/test_all.py`）为参照，旗舰插件需具备：内嵌"验证基准"场景、不确定度量化、发表级图表导出。选定领域：

- **酶动力学**（bio-enzyme）
- **空间插值**（spatialInterp）
- **地形水文**（terrain）
- **物理仿真**（nbody / doublePendulum）

### L5 教学玩具级处置 —— 挑选升级

13 个教学玩具级插件中，选取科研价值高的（**carbon、plume、groundwater3d、popPyramid、bio-popgen**）补数据输入、不确定度量化与统计诊断后转正；其余按 L1 标注"教学演示"徽章，移出默认科研入口但仍保留在市场目录可手动安装。

## 4. 路线图

| 阶段 | 内容 | 目标 |
| --- | --- | --- |
| Phase 1 | L1 基础设施 + 分级标注 + 出厂门禁落地 | 建立分级与一致性，消除"教学玩具感"主体 |
| Phase 2 | L2 补齐科学输出（约 20 个） | 准研究级插件全部达标 |
| Phase 3 | L3 数值内核升级（演示级） | 演示级随统计图表簇一并转准研究级 |
| Phase 4 | L4 旗舰深挖（4 领域） | 出现可与两个求解器对标的"研究级"标杆 |
| Phase 5 | L5 教学玩具处置 | 分类落地：升级 / 标注 / 保留手动安装 |

> 原则：模拟类插件严格数据驱动，不伪造默认场景；所有结论与参数必须可复现、可追溯。
