## 阅读路径

按角色推荐三条路径：

- **了解产品**：01 → 04 → 05。先看设计目标与功能全景，再看两种使用形态（工作台的四种模式与科研工具集的 19 个工具）。
- **参与开发**：02 → 03 → 04 → 08。先掌握分层与路由、插件契约与沙箱，再理解模式与共享 IR，最后按测试与 CI 的门禁要求接入改动。
- **评估科研能力**：05 → 07 → 06。先看科研工具提供了什么，再看它们背后的算法内核，最后看计算如何落到 GPU 与原生核心。
