# Ergalics Studio 产品介绍

Ergalics Studio 是一款完全运行于浏览器中的专业科学计算工作站：交互式数据探索、GPU 计算调度、沙箱化插件系统与四种面向不同用户的工作模式整合在同一个网页应用里，无需安装任何本地软件，打开网页即可使用。数据保存在浏览器本地（IndexedDB / OPFS），不出本机；项目以 MIT 协议开源，源码、测试与持续集成全部公开。本文面向评审给出总述——项目概览、技术创新、功能全景、场景落地、开源治理与长期发展；79 条细粒度应用场景见配套的《应用场景库》（第 11 篇 · 独立专题），工程细节见本目录其余技术文档。

## 一、项目概览

- **浏览器内零安装的全栈科学计算工作台。** 从拖入 CSV 看图、搭数据流管线、拼积木到写 Python / R / JavaScript，全链路在网页内完成，支持离线使用。
- **本地优先，数据不出本机。** 项目与数据存于浏览器 IndexedDB / OPFS，可导出 .clproj 文件离线流转，不存在云端副本；项目同时是 Git 仓库，版本历史留在本机。
- **MIT 开源。** 全部源码、173 个测试文件与 5 条 CI 工作流公开可查，发版经 Zenodo 归档并铸造 DOI。

## 二、技术创新

- **四模式同源 IR。** 积木、流程、代码三种模式经由同一份中间表示双向互转，配有专门的往返互转单元测试，端到端套件 verify-lang-modes 校验 Flow ⇄ Block ⇄ Code 无损循环；代码模式的缓冲区内容可解析回 IR，Python / R / JavaScript 三种语言之间可自由往返互译。同一条分析逻辑可以积木、流程图与脚本三种形态存在并随时切换。
- **浏览器内全栈运行时。** Python 由 Pyodide Worker 中的真实 CPython 执行（`studio` 作为可导入模块注入），R 由 vendored webR 0.6.0 运行时执行（资源缺失时回退 IR 引擎），持久化基于 IndexedDB 与 OPFS；Python / R 运行时 vendor 到本地自托管，不依赖公网 CDN，可离线使用。
- **真实 GPU 计算与优雅降级。** 14 个真实 WGSL 计算内核（含 D2Q9 流体、全对 N-Body、波动方程、FFT、K-means、SpMV）在 WebGPU 可用时由 GPU 执行，每个内核都配数学一致的 CPU 实现，单元测试对两条路径做数值一致性校验；数据规模低于阈值或设备缺失时自动回退 CPU，引擎选择写入运行记录，可追溯。
- **两个竞赛级求解器。** 电磁谐振特征值求解器面向十万阶非正定厄密稀疏矩阵，提供厚重启 Lanczos、块 LOBPCG 与 Jacobi-Davidson 三种内核，特征对经真实残差认证；1D–3D 双向耦合求解器以多速率时间步协调与粗-细时间子循环驱动 1D 管网–3D 场瞬态仿真，正反向边界耦合配守恒性审计。
- **沙箱 + 签名双防线。** 第三方包默认以隔离模式运行在 Web Worker 沙箱，经类型化 RPC 与宿主通信，画布渲染经 OffscreenCanvas 转移完成；`.cspkg` 包加载时做清单校验（必填字段、id 格式、入口路径穿越防护等），支持 Ed25519 签名与信任注册表（纯 TypeScript 自实现，不依赖 WebCrypto）。沙箱约束"能做什么"，签名回答"是谁发布的"，两道防线互相独立。

## 五、开源治理与质量

- **协议与合规。** MIT 协议；security 工作流做依赖安全扫描并产出 SBOM；CITATION.cff 由脚本与 `package.json` 比对作者 / 许可，漂移即以非零码退出使 CI 变红。
- **单元测试网。** 173 个测试文件、2815 个单元测试（2813 通过，2 个在无 GPU 环境跳过）；`npm run verify` 串联 `tsc --noEmit` 严格类型检查与全部单测，是贡献指引要求保持绿色的组合检查。
- **端到端。** 14 套 Playwright 套件（1 冒烟 + 13 个 verify 脚本）驱动真实无头浏览器对生产预览验证，断言真实像素与零控制台错误。
- **5 条 CI 工作流。** ci（引用元数据检查、类型、ESLint、单测、构建、性能预算）、bench（性能基线）、security（依赖安全 + SBOM）、release（发版归档，Zenodo 铸造 DOI）、deploy（构建部署与站点完整性校验）。
- **性能基线按环境分文件。** 性能与体积用基线对比而非固定阈值，基线按运行环境分文件保存，避免共享 Runner 上的噪声被误判为性能回归。
- **文档体系。** 01–08 八篇系列文档；09、10 两篇求解器独立专题（含容器化部署手册）；《应用场景库》速查附录；中英双语 README；全部文档提供合集 PDF。CONTRIBUTING、SECURITY、CODE_OF_CONDUCT、CHANGELOG 齐备。
- **第三方包规范。** `.cspkg` 清单规范与 Ed25519 签名、市场目录内建（按科学 / 趣味 / 工具三类组织），第三方与内置插件走同一条加载路径，生态在受控前提下生长。

## 六、长期发展

- **插件契约即扩展路径。** 第三方插件与内置插件走同一条加载、渲染、参数与数据访问路径，能力增长不依赖修改宿主，契约稳定即可持续接纳新学科。
- **GPU / CPU 双路径覆盖硬件寿命。** 每个计算内核都有数学一致的 CPU 实现，无 WebGPU 的老设备全功能可用，硬件差异不淘汰用户。
- **结果长期可重放。** 复现锁 repro.lock 锁定数据指纹、参数哈希、种子、代码快照与环境快照五类漂移判定，任何一次分析在多年后仍可判定漂移并一键重跑。
- **数据开放，不设锁定。** 本地优先、无账号；CSV / JSON / HDF5 / NetCDF / FITS / Zarr / Parquet 等开放格式自由进出，项目可导出为 .clproj 离线流转。
- **求解器可持续维护。** 两个竞赛级求解器各配独立专题文档（09、10 篇）与容器化部署手册，验收标准与部署流程成文可循。

## 七、运行与获取

- 在线演示：GitHub Pages（见仓库 README 徽章链接），打开即用。
- 本地开发：`npm install` 后 `npm run dev` 启动；`npm run build:web` 完成纯 Web 构建（原生核心以 Rust 源码交付，浏览器构建产物为占位桩，运行时计算完全由 WebGPU / CPU 承担）；`npm run build` 为完整构建。
- 质量检查：`npm test` 跑单元测试，`npm run verify` 先做 `tsc --noEmit` 严格类型检查再跑单测，`npm run test:e2e` 串联端到端套件。
- 开源协议：MIT，欢迎通过 Issue 与 Pull Request 参与贡献。
