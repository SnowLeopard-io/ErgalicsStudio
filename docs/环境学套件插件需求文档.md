# 环境学套件插件需求文档（PRD）

- 版本：v0.1 评审稿
- 日期：2026-10-04
- 适用项目：Ergalics Studio
- 文档性质：面向后续开发的纯文字需求文档（不含视觉原型）

---

## 1. 背景与动机

Ergalics Studio 当前在侧边栏按学科对插件分组（`src/plugins/categories.ts`），现有学科为：图表可视化、数学统计、物理模拟、化学、生物学、地理、数据与智能、趣味工具。其中地理学科（`geo` 套件）已覆盖气候直方图、太阳辐射、地形、地图、人口金字塔、空间插值等模块，与环境学在气候、人口等主题上有部分重叠。

用户提出：项目缺少一个独立的**环境学套件**，希望做成插件补充进来。需求在侧边栏分组上明确为**新增「环境」学科分组**，而非并入地理或数据分组。

环境学与地理学是不同的学科语境：地理侧重空间分布与制图，环境学侧重**环境监测 → 质量评价 → 系统模拟 → 生态诊断**这一条评价分析主线。因此本套件避开地理的空间成图能力，聚焦环境数据本身的录入、计算、评级与情景推演。

本套件应承接 Ergalics Studio 的既有插件机制与工作台能力（见 §5 架构落点），并补齐环境监测与生态分析这一空白。

---

## 2. 目标（定性目标）

- 覆盖高中/本科阶段环境科学课程最常见的十类分析场景：六类基础分析（空气质量评价、水质评价、温室效应模拟、碳循环推演、生物多样性指数、污染物扩散模拟）加四类高级 3D 模拟（3D 污染羽流、3D 湖泊水质分层、3D 全球环境、3D 地下水运移）。
- 每个模块遵循统一的「拖入数据 → 自动计算 → 单项指标评级 → 综合结论」使用路径，让用户输入原始观测数据即可得到结构化的环境判断，而无需手写评价流程。
- 所有计算给出可解释的依据（引用标准或公认模型），并对输入做边界校验，避免「越界仍出结果」。
- 3D 模拟模块定位教学示意与过程演示，不追求物理级预报精度。
- 套件在侧边栏以独立「环境」学科呈现，插件 ID 统一使用 `example.env-*` 前缀，与现有 `example.geo-*`、`example.chem-*` 风格一致。

**非目标**（本次不做）
- 不做空间制图/地图底图类能力（归属地理学科）。
- 不做面向合规报批的正式报告模板生成。
- 不接入实时监测硬件数据流，仅支持文件/数据导入。

## 3. 用户与核心场景

目标用户：环境学科任课教师、中学生实验课、基础环境数据分析者。

核心场景（按优先级）：
1. 学生把一段实测的空气监测表（SO₂、NO₂、PM2.5、PM10、CO、O₃）拖进工作台，一键得到当日 AQI 与主要污染物判定。
2. 教师把一组河湖水样的水质监测数据（pH、溶解氧、COD、BOD₅、氨氮、总磷）录入，绘制雷达图并给出地表水环境质量类别（Ⅰ–Ⅴ类）。
3. 学生通过调节温室效应模型的反照率/CO₂ 浓度滑块，观察辐射强迫与温升变化，理解温室效应的定性规律。
4. 学生输入一张物种丰度表，计算 Shannon/Simpson 多样性指数并对比两个样地的群落多样性。
5. 进阶：学生观察点源污染物在下风向的浓度扩散云图。

## 5. 架构落点（对应现有源码）

以下登记点决定了要把这套件真正接进工作台需要改动/新增的位置。均以本仓库现有源码为准。

- 修改 `src/plugins/categories.ts`
  - `PluginDiscipline` 联合类型加入 `'env'`。
  - `PLUGIN_DISCIPLINES` 数组新增 `{ id: 'env', nameI18n: { 'zh-CN': '环境', 'en-US': 'Environmental' } }`。
  - `DISCIPLINE_BY_PLUGIN` 为每个 `example.env-*` 插件 ID 登记到 `'env'`。

### 5.2 插件注册（builtin 目录）

- 在 `src/plugins/builtin/env/` 下为每个模块放置一个实现文件 + 一个 `*Manifest.ts`。命名风格对齐 `geo/` 套件：
  - 实现文件：`aqi.ts`、`water.ts`、`greenhouse.ts`、`carbon.ts`、`biodiversity.ts`、`plume.ts`、`plume3d.ts`、`lake3d.ts`、`earth3d.ts`、`groundwater3d.ts`。
  - 清单文件：`aqiManifest.ts`、`waterManifest.ts` 等，导出 `PluginManifest`。
  - 纯函数放入共享 `envCore.ts`（对比 `geo/geoCore.ts`），便于单测。
- 修改 `src/plugins/builtin/index.ts`：import 对应 manifest，并在内置插件数组中追加 `{ manifest, load: async () => (await import('./env/aqi')).default() }` 形式的注册块。参照 `geo` 各插件的 `load` 写法。

### 5.3 市场元数据

- 修改 `src/plugins/marketplace.ts`：为每个 `example.env-*` ID 新增条目，含 `category: 'scientific'`、`tags`（如 `['environment','air-quality','aqi']`）、`popularity`。参照现有 `example.geo-*` 条目写法。

### 5.4 示例数据

- 修改 `src/core/examples.ts`：按 `example.geo-climograph` 的数据项模式，为每个模块登记 1–3 个示例 CSV，包含 `pluginId`、`content`、`nameI18n`、`descriptionI18n`。示例数据用于顶栏「示例」对话框一键载入。

### 5.5 中英双语

- 每个模块的 `manifest`、参数、按钮标签、图标题均提供 `zh-CN` 与 `en-US` 两套文案，沿用 `isZh(this.api.locale)` 的判定习惯（见 `geo/geoCore.ts`）。

### 5.6 测试登记

- 参照 `tests/geoPlugins.test.ts` 的结构，为环境套件新增 `tests/envPlugins.test.ts`，对 `envCore.ts` 的纯函数（浓度→指数、达标判定、指数计算等）做单元测试，并对示例数据做载入冒烟。注册脚本沿用 `package.json` 的 `npm test`（vitest run）。

### 5.7 与既有机制的复用

- 插件接口遵循 `src/types/plugin.ts`：`Plugin` 接口、`ParamDefinition`（range/select/number/checkbox/text/file/button/toggle）、`ContainerCapabilities`、`PluginApi`。
- 若需将结果送入 Figure Studio，参考 `geo/climograph.ts` 中 `pushPanelsToFigure`（位于 `geo/geoFigure.ts` / `shared/enhance.ts`）的模式，生成本套件独立的图表面板。
- 3D 模块遵循宿主 3D 插件契约：实现 `renderToScene(scene: Scene3DHandle)` 生命周期钩子，宿主仅在插件声明 `renderToScene` 时才挂载 `container.three`（见 `geo/globe.ts`、`voxel3D.ts` 的写法）；交互统一为 OrbitControls（拖拽旋转 / 滚轮缩放），导出走 `Scene3DHandle.snapshot({ transparent: true })` 得到透明背景 PNG。
- 3D 模块的密集格点计算走 `fluid-cfd-coupler/` 的 worker + WebGPU/WGSL 通道；`PluginApi.gpu` 不可用（无 WebGPU 设备）时自动回退 CPU 计算。

## 6. 功能需求详述

### 6.1 模块一：空气质量评价（AQI）

**业务逻辑**
用户拖入或载入一份空气监测表（CSV，至少含污染物浓度列），或直接在各污染物的浓度输入框中填写数值。插件逐项计算单污染物空气质量分指数 IAQI，取各污染物 IAQI 的最大值为当日 AQI；据此输出：AQI 数值、空气质量级别（优/良/轻度污染/中度污染/重度污染/严重污染）、首要污染物、健康提示。评价依据遵循《环境空气质量指数（AQI）技术规定（试行）》（HJ 633-2012）与《环境空气质量标准》（GB 3095-2012）的分段线性插值方法；涉及的污染物为 SO₂、NO₂、PM2.5、PM10、CO、O₃。

**交互路径与反馈**
载入成功后顶部显示 AQI 大数与级别徽标；下方列出各污染物的 IAQI 条形图，标注贡献最大者为首要污染物。切换「现行标准」时需支持中国国标为主（GB/HJ），并预留美国 EPA 分段作为对照（[待确认]）。当任一浓度超出分段上限时，对该项给出「超出评价范围」提示而非直接外推结果。空数据时进入空态，提示拖入 CSV 或打开示例。

**输入参数（getParams 对应 ParamDefinition）**
| 参数 key | 控件类型 | 说明 | 默认 |
|---|---|---|---|
| 浓度 SO₂/NO₂/PM2.5/PM10/CO/O₃ | number | 各污染物小时/日平均浓度（按标准单位） | 留空 |
| standard | select | 评价标准（GB/HJ 或 US EPA） | GB/HJ |
| 首要污染物显示 | checkbox | 是否在图标注主要污染物 | 开 |

**数据契约**
| 列名（接受别名） | 单位 | 必填 |
|---|---|---|
| so2 / SO₂ | μg/m³ | 否（缺失项不计入 IAQI 取 max） |
| no2 / NO₂ | μg/m³ | 否 |
| pm25 / PM2.5 | μg/m³ | 否 |
| pm10 / PM10 | μg/m³ | 否 |
| co / CO | mg/m³ | 否 |
| o3 / O₃ | μg/m³ | 否 |

**边界与异常**
- 至少一项有效浓度，否则空态。
- 负浓度/非数值自动剔除并计数提示。
- 缺失项不参与 IAQI 最大值计算，结果需标注「部分污染物计算」。

### 6.2 模块二：水质评价（地表水分类 / WQI）

**业务逻辑**
用户载入水样指标表或逐项填写，指标包括 pH、溶解氧 DO、高锰酸盐指数/COD、BOD₅、氨氮 NH₃-N、总磷 TP 等。插件按《地表水环境质量标准》（GB 3838-2002）的分级限值，将每项指标归类到 Ⅰ–Ⅴ 类，给出「超标项提示」与一个综合的水质类别判定（取最差类别，对标超标项最多的原则）。同时支持输出一个可选的水质指数 WQI 数值（[待确认]采用的分法说明写入帮助）供横向比较。

**交互路径与反馈**
载入后默认绘制各指标实测值相对标准限值的雷达图（六边形），超标指标用语义色标出；下方输出：综合类别、超标指标清单、建议的后续关注项。pH 与 DO 需特殊处理高/低双向限值，不适用「越大越好」的单向判定。

**参数面板**
| 参数 key | 控件类型 | 说明 | 默认 |
|---|---|---|---|
| 是否纳入 BOD₅ | checkbox | 数据不足时选否 | 开 |
| 输出 WQI | checkbox | 是否显示综合水质指数 | 开 |

**数据契约**
| 列名 | 单位 | 备注 |
|---|---|---|
| ph | 无量纲 | 双向限值 6–9 |
| do / 溶解氧 | mg/L | 双类限值 |
| cod / 高锰酸盐指数 | mg/L | |
| bod / BOD₅ | mg/L | |
| nh3_n / 氨氮 | mg/L | |
| tp / 总磷 | mg/L | |

**边界与异常**
- 缺项需明确标注「未纳入该项评价」，避免被误读为合格。
- 缺项过多（少于 3 项）时提示数据不足，不建议给综合类别。

### 6.3 模块三：温室效应模拟

**业务逻辑**
本模块为参数驱动的辐射收支简化模型：输入 CO₂ 浓度、地表反照率、云量等参数，插件用已知的辐射强迫公式与气候敏感度常量估算地表平衡温度的增量（ΔT）。目的不是逼近真实气候预报，而是让学生观察「增大 CO₂/降低反照率 → 辐射强迫↑ → 平衡温升↑」的单调趋势。计算需给出所用公式与假设（常设有效温度、单一辐射层、平衡态假设），避免被当作预测工具。

**交互路径与反馈**
载入即基于默认参数在画布上呈现两栏（当前平衡温度、参数改变后的 ΔT），拖动 CO₂ 滑块或反照率滑块即时重算并更新结论文字。提供一个「回到初始参数」按钮，将各滑块复位到默认值（对应既有产品「重置」交互的亲和度要求）。

**参数面板**
| 参数 key | 控件类型 | 说明 | 默认 |
|---|---|---|---|
| co2 | range（滑块） | CO₂ 浓度 ppm | 420 |
| albedo | range | 地表反照率 | 0.30 |
| cloud | range | 云量（仅影响热力近似，可选） | 0.5 |
| 显示公式 | checkbox | 在结果下方是否显示所用公式 | 开 |
| 重置 | button | 复位到初始参数 | - |

**边界与异常**
- CO₂ 浓度限制在合理范围（如 180–1200 ppm）并提示模型适用范围，越界时禁用计算并说明。
- 说明该结果仅用于教学定性观察，标注「不能用于预测真实气候」。

### 6.4 模块四：碳循环推演

**业务逻辑**
采用 box 模型把地球碳库划分为大气碳库、陆地植被、土壤、海洋等若干库，各库之间以年通量相连（如光合吸收、呼吸、海洋吸收、人为排放）。用户可设定初始库存量与通量（或使用预设情景），插件按时间步进求解库存量变化，并输出：各库余额随时间曲线、年增减量、是否为净汇/净源。通量守恒需满足库间流入流出平衡检查。

**交互路径与反馈**
载入后显示各碳库的当前库存（单位 GtC）与库间通量箭头图；拨动「人为排放」滑块或选择预设情景（工业时代/当前/减排情景）后曲线与汇源标签即时重算。库存为 0 或出现负值时的处理需提示模型局限，而非直接展示矛盾结果。

**参数面板**
| 参数 key | 控件类型 | 说明 | 默认 |
|---|---|---|---|
| 情景 | select | 预设情景（工业时代/当前/减排） | 当前 |
| 人为排放 | number | 人为净排放 GtC/yr | 9 |
| 时间步长 | number | 模拟年数 | 100 |
| 重置 | button | 复位默认情景 | - |

**数据契约**
预设情景在插件内部内置；如需扩展，可载入自定义 CSV（`pool,initial_gtc,flux_in,flux_out`）覆盖初始库存与通量（[待确认]阶段二是否开放自定义）。

**边界与异常**
- 时间步长上限与年数上限在插件内做硬限制，防止长循环卡住浏览器。
- 平衡校验误差超阈值时给出警告而非静默接受。

### 6.5 模块五：生物多样性指数

**业务逻辑**
用户载入两个以上样地的物种丰度表（每列一个样地/处理，每行一个物种及其个体数），插件计算每样地的物种数（丰富度 S）、Shannon 指数 H′、Simpson 指数（1−Σpᵢ²）、均匀度；并在样地间做横向对比与简单解读（哪个样地多样性更高、由哪个物种主导）。指数计算为通用生态学定义，需在数据契约说明输入为个体数与两两对齐的完整样地矩阵。

**交互路径与反馈**
载入后以表格列出各指数；同时把两个样地的丰度占比绘成堆叠条形或扇形示意并标注优势种。提供「导出 CSV」按钮，将计算结果下载到本地（复用 `PluginApi.exportFile`）。

**参数面板**
| 参数 key | 控件类型 | 说明 | 默认 |
|---|---|---|---|
| 指数选择 | checkbox 组（或 multi） | Shannon / Simpson / 均匀度 | 全选 |
| 导出 CSV | button | 导出指数结果 | - |

**数据契约**
| 列名 | 说明 |
|---|---|
| species | 物种名 |
| site_1..site_n | 各样地个体数（数值） |

**边界与异常**
- 某样地个体总数为 0 或为空 → 该项指数显示「—」并跳过对数计算，避免 NaN/负无穷。
- 样地列数不一致时按最小公共列处理并提示。

### 6.6 模块六：污染物扩散模拟（高斯烟羽）

**业务逻辑**
采用高斯烟羽模型，按连续点源下风向浓度公式，结合用户设定的源强 Q、风向风速 u、下风向距离/横向分布 σy、σz（可按典型稳定度等级取值）计算二维浓度场；用色阶云图呈现下风向羽流扩散形态。默认提供教学用场景（烟囱点源、固定气象条件）。

**交互路径与反馈**
载入后在画布渲染下风向浓度热力云图，拖动源强/风速/稳定度滑块即可重绘；顶部显示最大落地浓度所在位置。支持把浓度场作为面板推送进 Figure Studio 导出。密集格点计算在数据规模较小时走 CPU，规模较大时参照 `fluid-cfd-coupler` 走 worker/GPU 通道。

**参数面板**
| 参数 key | 控件类型 | 说明 | 默认 |
|---|---|---|---|
| 源强 Q | number | 排放速率 | 100 |
| 风速 u | range | 平均风速 m/s | 4 |
| 稳定度等级 | select | A–F 等级 | C |
| 面元数 | number | 网格密度 | 60 |

**边界与异常**
- 风速为 0 时模型不适用，禁用计算并提示「静风条件不适用高斯烟羽」。
- 网格过大时自动限制或降采样，防止卡顿。

### 6.7 模块七：3D 污染羽流扩散（env-plume3d）

**业务逻辑**
在三维空间中按高斯烟羽模型计算连续点源的下风向浓度场：有效源高 H（烟囱抬升高度）、横向/垂直扩散参数 σy/σz 按稳定度等级取值，浓度公式与 `env-plume` 共用同一套内核。三维浓度场以体素浓度云或等值面（3D marching cubes）呈现，可叠加 3D 地形作为下垫面（复用 `geo/terrain3d.ts` 的地形网格）。格点规模较大时经 worker 走 WebGPU/WGSL 通道，无 WebGPU 设备时回退 CPU，计算不阻塞主线程。

**交互路径与反馈**
激活后宿主挂载 3D 场景（`container.three`），OrbitControls 拖拽旋转、滚轮缩放。拖动源强/风速/稳定度/源高滑块即时重绘等值面；「显示横切面」开关查看下风向某断面的浓度分布；色标图例显示浓度区间；`snapshot({ transparent: true })` 导出 PNG 供 Figure Studio 或本地下载。顶部显示最大落地浓度所在位置。

**参数面板**
| 参数 key | 控件类型 | 说明 | 默认 |
|---|---|---|---|
| 源强 Q | number | 排放速率 | 100 |
| 风速 u | range | 平均风速 m/s | 4 |
| 稳定度等级 | select | A–F 等级 | C |
| 有效源高 H | number | 烟囱有效排放高度 m | 50 |
| 网格分辨率 | number | 三维格点密度 | 60³ |
| 显示横切面 | checkbox | 是否显示下风向断面 | 关 |
| 重置 | button | 复位初始参数 | - |

**数据契约**
无文件也可运行（内置教学场景）。可选 CSV `x,y,z,conc` 覆盖浓度场，支持导入外部模拟结果用于对比展示。

**边界与异常**
- 风速为 0 时禁用计算，提示「静风条件不适用高斯烟羽」。
- 三维格点数超过上限时自动降采样或提示，防止卡顿。
- 等值面阈值低于最大浓度 1% 时提示调整阈值。

### 6.8 模块八：3D 湖泊水质分层（env-lake3d）

**业务逻辑**
三维湖盆水体模型：以垂直热分层为核心，展示温度随深度剖面（表层温水层 / 温跃层 / 深层冷水层）、溶解氧 DO 分层（表层富氧、深层缺氧）、入流/出流引起的密度流，以及营养盐负荷驱动的表层富营养化（藻华）示意。分层结构采用简化模型（混合层-深层两段，或按实测剖面线性插值），3D 渲染呈现湖盆形态与垂直切片，与 `env-water` 的评价结论呼应。

**交互路径与反馈**
3D 场景显示湖盆与垂直切片；拖动入流温度/混合风速/营养盐负荷滑块即时更新分层结构与剖面曲线；点击切片上的测点显示该深度的温度与 DO 数值；`snapshot({ transparent: true })` 导出 PNG。

**参数面板**
| 参数 key | 控件类型 | 说明 | 默认 |
|---|---|---|---|
| 湖深 | number | 最大水深 m | 30 |
| 入流温度 | range | 入流河水温度 ℃ | 20 |
| 混合风速 | range | 影响混合层厚度 m/s | 2 |
| 营养盐负荷 | range | 相对负荷（标幺） | 0.5 |
| 显示切片轴 | select | 展示剖面方向 | X |
| 重置 | button | 复位初始参数 | - |

**数据契约**
无文件默认分层场景。可选 CSV `depth,temp,do` 实测剖面覆盖默认分层，实测点少于 3 个时提示数据不足。

**边界与异常**
- 湖深为 0 或负值禁用计算；实测剖面深度非递增时按排序处理后提示。
- 水温越出合理范围（0–40 ℃）时钳制并提示。
- 模型为简化分层，输出标注「教学示意」，不用于真实水体预测。

### 6.9 模块九：3D 全球环境（env-earth3d）

**业务逻辑**
三维地球上的环境要素示意：全球 CO₂ 浓度分布色带、洋流方向示意箭头、地表反照率与辐射收支图层。数据为内置近似分布（教学示意，非再分析数据产品），图层可切换，时间滑块浏览季节变化。球体渲染复用 `geo/globe.ts` 的路径（纹理球 + 数据叠加层），本模块不再重复实现球体基础。

**交互路径与反馈**
3D 球体 OrbitControls 旋转缩放；图层 select 切换（CO₂ 浓度 / 洋流 / 反照率）；时间滑块推进季节变化；色标图例显示数值范围；`snapshot({ transparent: true })` 导出 PNG。

**参数面板**
| 参数 key | 控件类型 | 说明 | 默认 |
|---|---|---|---|
| 图层 | select | CO₂ 浓度 / 洋流 / 反照率 | CO₂ 浓度 |
| 时间 | range | 月份（1–12） | 1 |
| 显示色标 | checkbox | 是否显示图例 | 开 |
| 重置 | button | 复位初始参数 | - |

**数据契约**
全部要素为内置近似分布，不接入外部文件；数据来源与精度说明写入插件帮助（[待确认] 数据版本与来源）。

**边界与异常**
- 图层切换不中断当前视角（相机姿态保持）。
- 界面明确标注「示意性展示，非观测数据产品」。

### 6.10 模块十：3D 地下水运移（env-groundwater3d）

**业务逻辑**
三维含水层中污染物运移模拟：体素浓度场（复用 `voxel3D.ts` 的体素渲染模式），叠加 Darcy 流方向箭头、污染源与抽水井位置。浓度演化按对流-弥散方程的简化显式求解（时间步进受数值稳定约束），演示地下污染羽的扩展、迁移与抽水影响。

**交互路径与反馈**
3D 体素浓度云旋转缩放；拖动渗透系数/水力梯度/弥散度/污染源位置滑块重算；时间步进动画播放/暂停；顶部显示污染羽前锋到达最近抽水井的模拟时刻；`snapshot({ transparent: true })` 导出 PNG。

**参数面板**
| 参数 key | 控件类型 | 说明 | 默认 |
|---|---|---|---|
| 渗透系数 | number | 含水层渗透系数 m/d | 10 |
| 水力梯度 | range | 无量纲 | 0.005 |
| 弥散度 | number | 纵向弥散度 m | 10 |
| 污染源位置 | number×2 | 源点 (x, z) | (0.25, 0.5) |
| 时间步进 | toggle | 播放/暂停 | 播放 |
| 重置 | button | 复位初始参数 | - |

**数据契约**
无文件默认场景；可选 CSV 体素/剖面浓度数据覆盖（[待确认] 是否开放自定义导入）。

**边界与异常**
- 体素数上限硬限制（防卡顿）；时间步长受数值稳定约束，越界时提示而非静默发散。
- 渗透系数越出合理范围（0–100 m/d）时禁用计算并说明。
- 模型为教学简化求解，输出标注「示意性模拟」。

## 7. 通用需求（跨模块约束）

- **原始数据不可修改**：所有模块只读用户导入文件，计算结果仅在内存中生成派生状态；不写回、不覆盖源文件。导出为下载新文件。
- **重置与重置插件**：每个模块提供「重置」按钮将所选反应/参数复位到初始状态；在插件级别需要提供「重置插件」能力，把整个插件恢复到出厂默认（对应产品既有 reset 交互的进一步诉求），实现为对 `setParam` 的默认值批量复位 + `reload`。
- **空态**：未载入数据时，各模块均显示统一空态提示（建议文案：拖入示例数据或从顶栏示例对话框载入），不显示 0 值结果。
- **状态回写**：计算开始/完成/失败时通过 `PluginApi.setStatus` 与 `notify` 给出反馈；输出数据规模上报 `reportDataScale`。
- **双语**：全部文案在中英两套图中一致。
- **错误可见性**：不符合格式的文件给出明确 toast 提示，不静默失败。
- **3D 与 GPU 回退**：3D 模块在无 WebGPU 设备时自动回退 CPU 计算（检查 `PluginApi.gpu.available`），不阻塞渲染；3D 视图统一使用宿主 OrbitControls，导出走 `Scene3DHandle.snapshot`。

## 10. 落地顺序建议

1. 阶段一两个模块（AQI、水质）：数据即用、结论直观，优先交付并作为套件样板。
2. 在阶段一验收并锁定统一交互范式后，推进阶段二（温室效应、碳循环）两个滑块驱动模型。
3. 阶段三（多样性、烟羽）：多样性复用表格计算，烟羽复用 CFD 基础设施复杂度最高。
4. 阶段四 3D 模块最后推进：先 3D 羽流（复用 CFD 的 WebGPU 通道与 `geo/terrain3d.ts` 地形），再 3D 湖泊与 3D 地下水（复用 `voxel3D.ts` 体素渲染），最后 3D 全球环境（复用 `geo/globe.ts` 球体渲染）。
