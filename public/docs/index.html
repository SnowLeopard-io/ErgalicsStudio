Ergalics Studio

浏览器端科学计算工作站 · 技术文档

架构

Ergalics Studio 分为三个层次：

  1. 原生层（Rust + WASM）：WebGPU 设备管理与 Compute 调度框架，产物为 src/native/ergalics_core.js。
  2. 宿主层（React + TypeScript）：核心服务、状态管理、插件注册表与生命周期管理。
  3. 插件层：第三方通过 .cspkg 包注入计算能力。

插件开发

插件为 ESM 模块，导出工厂函数返回实现了生命周期接口的对象：

export default function createPlugin() {
  return {
    manifest: { id, name, version, author, description, entry },
    init(api) {},
    activate(ctx) {},  // 接管 ctx.container
    deactivate() {},
    destroy() {},
    render(container) {},
    updateParams(params) {},
    getParams() { return []; },
    getSupportedFormats() { return []; },
  };
}

完整类型见 src/types/plugin.ts，示例见 src/plugins/builtin/。

常用命令

  • npm run build:wasm — 编译 Rust 原生层到 src/native/
  • npm run dev — 开发服务器
  • npm run build — 类型检查 + WASM 编译 + 生产构建
  • npm run preview — 预览构建产物

数据与存储

  • 项目 / 插件包：IndexedDB（ergalics-db）
  • 偏好设置：localStorage（ergalics.*）
  • 分享链接：lz-string 压缩后放入 URL Hash
