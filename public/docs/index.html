Docs site

The documentation is a standalone VitePress workspace in docs/:

  • cd docs && npm install && npm run dev — local docs site
  • npm run build:docs — build and copy into dist/docs/
In production builds this page is replaced by the generated documentation site (guide, plugin development, architecture, native core & WebGPU, testing, roadmap).
