# 简介

**Ergalics Studio** 是一款完全在浏览器中运行的专业科学计算工作站。它将 React + TypeScript 前端、编译为 WebAssembly 的 Rust 核心和 WebGPU 计算管线结合起来，并将第三方扩展能力视为一等关注点。

## 目标

| 目标 | 含义 |
| --- | --- |
| **浏览器原生** | 无需安装，也无需服务器；数据存储在 IndexedDB 中，可通过 `.clproj` 文件共享。 |
| **为扩展而设计** | 每一种可视化都是基于精简的类型化契约实现的插件；第三方包与宿主页面隔离。 |
| **工业级工程规范** | 严格的 TypeScript、单元和端到端测试、确定性的示例数据生成流程，以及生成并纳入版本管理的 WASM 绑定。 |

## 当前状态

项目正在**积极开发**，目前已可端到端使用。以下功能现已可用：

| 领域 | 当前可用功能 |
| --- | --- |
| 完整的工作台流程 | 项目、包含逐文件编辑器和标签式中央区域的文件浏览器、文件路由、插件注册表、参数面板、状态栏和性能栏。 |
| 四种工作台模式 | 标准模式（拖入 → 查看）、流程模式（组合数据流 DAG → 运行）、积木模式（Scratch 风格的脚本编辑器，具有“运行”帽子积木、40 个内置积木、共享 IR 和 5 个示例程序）以及代码模式（在 Pyodide CPython Worker 中自由编写 Python，带 REPL 控制台和 9 个示例程序）。三种脚本模式共享一个 IR，积木 ↔ 流程 ↔ 代码的往返转换由 `sync-threeway` 测试保证。文件决定打开模式：`.py`/`.js`/`.r` 在 Monaco 编辑器中打开，`*.flow.json` 在流程 DAG 编辑器中打开，`*.block.json` 在 Blockly 编辑器中打开。 |
| 165 个内置插件 | （155 个产品插件 + 10 个趣味/实用工具），在侧边栏按 19 个学科组织，覆盖 2D 和 3D 渲染路径——包括三维 N 体引力模拟器（天体物理学）、使用力导向布局的蛋白质相互作用网络（系统生物学）、D2Q9 格子玻尔兹曼流体/波动方程/双摆模拟、离线 GeoJSON 分级设色地图、三个交互式物理实验室（电磁学、光学、结构力学）、浏览器内 AI 训练器（基于 TensorFlow.js 的线性/非线性神经网络/逻辑回归/MNIST CNN），以及两个面向实际应用的竞赛求解器：稀疏厄密特征值求解器（`em-eigensolver`）和 1D–3D 双向流体网络耦合器（`fluid-cfd-coupler`）；两者均在 Pyodide Worker 中运行，并配备毫秒级控制工具。 |
| 科学计算子系统 | 纯 TypeScript 实现：统计内核（假设检验、效应量、校正、功效分析）、科学二进制 I/O（HDF5 / NetCDF / FITS / Zarr / Parquet）、出版级 SVG/PDF 绘图引擎，以及可复现性内核（带种子的随机数生成器 + 运行清单）。 |
| WebGPU 计算管线 | 实际计算功能：由 Rust 管理 `GpuBuffer` 并编译、调度和运行内核；为插件提供 `api.gpu` 计算接口；提供带 CPU 后备路径的可复用 WGSL 模板——加速粒子、N 体引力、LBM 流体、波动方程、直方图、热力图和点云内核。 |
| 插件沙箱 | 基于 Worker，使用类型化 RPC 协议。 |
| Git 支持的项目 | 工作区 VFS（`src/core/vfs/`）由文件浏览器、逐文件编辑器和 Git 工作树共享；浏览器中使用 isomorphic-git，Node 下使用 simple-git，并提供侧边栏 Git 面板（分支/提交/克隆/远程同步/自动提交/预装钩子）。 |
| 国际化 | zh-CN / en-US 响应式语言切换——积木模式使用 Blockly 的 `BKY_*` 键系统，使积木标签随其余界面一起重新本地化。 |
| 主题/共享/CI/测试 | 主题（深色/浅色）、共享、GitHub Actions CI 和自动化测试（263 个测试文件中的 4078 个 Vitest 测试用例——4076 通过、2 个跳过，以及 Playwright 端到端测试套件）。 |

已构建但尚未作为产品发布：插件市场全自动第三方提交与安装流程（`.cspkg` 包签名门禁——ed25519，FR-05——已经上线；见 `SECURITY.md`）。代码模式的 R 是完整的 webR 运行时（已放入 `public/webr/`；缺少该包时回退到内置 IR 引擎）——见 `guide/roadmap`。

> 目标是在这一结构**内部**增加功能，让代码库不断成长为生产系统，而不是重写它。
